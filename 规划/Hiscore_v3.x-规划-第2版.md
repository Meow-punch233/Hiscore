# Hiscore v3.x 更新规划 · 第 2 版

> 日期：2026-11-19
> 状态：Aki 已确认「工作台收口 + 对话壳」，待按本版实施。
> 承接：`Hiscore_v3.x-规划-第1版.md` 的版本范围不变；本版补上信息架构和智能体页形态。
> 实施目录：继续放在 `迭代版本/S3/v3.0.alpha/`，先改 `Hiscore_v3.0.alpha.html`。通过验收前不同步 `newest-version/`（当前稳定版仍为 v2.5）。

## 1. 仍不变的范围

v3.x 只做两件事：把双智能体从「框架」做成可用，同时继续打磨校园像素视觉。

v4.0 另开大版本，做初中课程 / 大学课程，以及自定义课程和评判标准。不把课程体系或计分规则改动提前掺进 v3。

约束保持不变：

- 不把未接入能力写成已可用；不做假聊天、假路由、假生成。
- 旧学生 AI 在新运行时通过验收并经 Aki 确认前，不撤掉。
- 不改统计公式、身份规则和 `LS_*` 键名。
- 保持单文件离线；不加外部字体或 CDN，不换企业后台皮肤。
- 大改先给 Aki 看；验收通过后再考虑同步稳定版。
- 推送到 GitHub 私密库改为每周五晚上一次，先给 Aki 看清单再推，不在每次出结果后立刻推送。

## 2. 为什么要补这一刀

v3.0.alpha 已做过智能体页分栏，以及一轮间距和视觉微调。页面好看了一点，但总览和智能体页仍把功能一块块平铺，像早期门户或搜索引擎首页：每个板块份量差不多，一眼看不出先干什么。

下一刀不再调间距，改为「工作台收口」：一页一件主事。这一刀仍放在 v3.0 验收里，先不要开 v3.1（小懂弟成绩分析接入）。

## 3. 总览：先看结论，再翻详情

总览的主事是「这场考试先看什么」，不是把所有模块摊开。

- 筛选（考试场次、班级、选科组合）收到顶栏或一条轻量工具条，不要再占一张大卡片。
- 上层只留这场考试的核心数字，以及最该关注的人：临界生、连续退步、偏科预警。
- 完整成绩表和 PDF 导出是工具，放到后面或收起来，不要跟洞察抢位置。
- 进步最快、退步最多、各科均分等次要名单和图表，放进「再看」折叠或次要区域，默认不要和主结论同等份量。
- 班级 PK 入口可以保留为轻量跳转，不要做成又一块门户广告。

## 4. 智能体页：对话壳，接上模型后再真聊

参考 Knowunity 一类学习应用的对话面板：中间是吉祥物，下面是一句输入和几个动作按钮。这是工作台，不是能力目录。

- 大学姐页打开就是教师工作入口，主按钮是「成绩导入」；点开后进入现有本地导入工具（粘贴 / Excel、预览后写入），不要把整套导入控件直接堆在形象旁边。
- 小懂弟页打开就是学生事务入口，主按钮是「成绩分析」；点开后走现有学生 AI，不撤旧入口。
- 「未接入」收成一行说明或折叠，不要再摆成功能卡片墙。
- 输入框现在就放上，作为以后的对话入口。模型尚未接入时如实说明「尚未接入」，不要生成假回复、假路由、假结果。
- 真接上 AI 后，同一条输入、同一块面板就能对话，不必再换一套界面。
- 不要搬扫描、测验、练习等与哈绩咪无关的动作。保持「校园像素 + 哈绩咪」（森林绿、奶油纸、黄铜、橘色），不要做成深色通用聊天产品。

## 5. 切片顺序（更新）

### v3.0：验收、必要修补，以及本版的工作台收口

不接新能力。先按本版收口总览和智能体页，再由 Aki 验收（含本地双击打开和实体手机效果），通过后再决定是否进入后续切片。

### v3.1 及之后

仍按第 1 版：v3.1 小懂弟成绩分析，v3.2 大学姐教师工作流，v3.3 路由与个性化。智能体页的对话壳要为这些接入留好位置，但在对应切片完成前不得假装已经可用。

贯穿 v3.x 的视觉约束不变：动效只用于反馈和空间连续性；`prefers-reduced-motion` 下关闭非必要动画；完整单班详情仍排在 v3.x 后段。
