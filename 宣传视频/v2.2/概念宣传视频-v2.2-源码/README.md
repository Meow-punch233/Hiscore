# 宣传视频源码 · 像素风 · 第 1 版

《哈绩咪 Hiscore v2.2》宣传视频（73 秒）的全部生成代码，纯 Python 画帧 + ffmpeg 合成。
成品：`../宣传视频-像素风-第1版.mp4`

## 文件说明
| 文件 | 作用 |
|---|---|
| `engine.py` | 渲染引擎：调色板、字体、缓动、像素组件（面板/雷达图/图标/吉祥物/像素溶解转场） |
| `scenes.py` | 9 个场景的绘制函数（深夜 Excel → 双击 → 导入 → 算分 → 重点关注 → 学生诊断 → 班级对比 → 数据安全 → 落版） |
| `render.py` | 渲染管线：逐帧绘制 → ffmpeg 合成 1080p30 → 混入 BGM |
| `music.py` | 芯片风 BGM 生成器（方波旋律 + 三角贝斯，C-G-Am-F，82 秒） |
| `bgm.wav` | `music.py` 的输出（改了音乐代码后重新跑一次即可覆盖） |

## 重新生成
```bash
python3 music.py      # 改过配乐才需要
python3 render.py     # 全片渲染 + 混音，输出到上级文件夹
```
依赖：Python 3 + Pillow + numpy + ffmpeg。渲染约 2190 帧，几分钟。

## 改内容
- 改文案/时长/动画 → 编辑 `scenes.py` 里对应场景函数（每个函数头部注释是分镜时间轴）
- 改配色 → `engine.py` 的 `PAL`；改字体大小 → 各场景里的 `font(...)`
- 场景时长在 `scenes.py` 末尾 `SCENES` 表的 `dur` 字段（改完总长会变，BGM 自动截断/延长匹配）
