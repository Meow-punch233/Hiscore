# Hiscore 1.0「班级 PK」设计方案 · 第1版

> 一句话：给每个班级一个 IP 形象 + 名字 + 口号，让班级在**阵列、榜单、擂台**三个场景里"有脸、有声、有戏"地 PK。

**现状基础**：`Hiscore_preview.html`（单文件 HTML + localStorage，无依赖）已有 4 个标签页（总览 / 学生追踪 / 成绩录入 / 设置），V4.0 已支持多班（`settings.classes` 可增删、支持拼班组合），吉祥物「哈绩咪」已嵌入页头。1.0 在此基础上做「班级 PK」。

---

## 1. 需求对照

| 你的需求 | 设计落点 |
|---|---|
| ① 每班有自己的 IP 形象，参与排名、优劣势科目比较、展示排列 | 班级档案 + 形象库 + PK 三视图（§4、§6） |
| ② 默认 9 个班、数量可自定义 | 「一键生成 9 班模板」+ 设置页增删（§5） |
| ③ 每班可取名字、有自己的口号 | 班级档案字段 + 全场景展示（§5） |
| ④ 班级间 PK/排名动画动效 | 颁奖动效 + 对战动效两套（§7） |

---

## 2. 功能结构

新增第 5 个标签页 **「班级 PK」**（放在「总览」之后），内含三个视图：

```
总览 │ 班级PK │ 学生追踪 │ 成绩录入 │ 设置
        ├── 擂台 · 两班对战（动画主秀）
        ├── 榜单 · 全班排行（颁奖动画）
        └── 阵列 · 战队总览（3×3 卡片墙）
```

「总览」页顶部加一张「班级 PK」入口卡（带当前第 1 名迷你展示），点进来即 PK 页。

---

## 3. 数据设计

现有 `settings.classes` 向后兼容地扩展（旧数据缺字段自动补默认值，沿用 V4 的迁移习惯）：

```js
// 现在
{ id: 'c1', name: '高三(1)班', comboIds: ['wu-hua-di'] }

// Hiscore 1.0
{
  id: 'c1',
  name: '高三(1)班',
  slogan: '笃学慎思，力争上游',   // 口号，≤16 字
  mascot: 'm-01',                 // 形象库 ID，或 'custom:<压缩图base64>'
  color: '#b4472e',               // 代表色（战队色）
  comboIds: ['wu-hua-di'],
}
```

```js
// 形象库（内置预设，常量；自定义上传走 mascot 字段）
const MASCOTS = [
  { id: 'm-01', name: '哈绩咪',   src: '...（现有 PNG）' },
  { id: 'm-02', name: '待命名',   src: '...' },
  // ……9~12 只
];
```

**PK 指标口径**（纯函数，放 `__CORE_START__` 区，可独立测试）：

- 班级总均分 / 中位数（按现有成绩行聚合）
- 上线率（沿用 V4「上线」口径）
- 进步幅度（本次均分 − 上次均分）
- 单科均分（优劣势比较的核心）
- 公平性规则：**只 PK 两班共同开设的科目**；总分对比沿用 V4 的口径提示风格（拼班 / 物理类 vs 历史类注明口径）。

## 4. PK 三视图

### 4.1 阵列（战队总览）

3×3 战队卡网格（9 班时正好一屏），`auto-fit` 自适应——12 班换行、5 班居中，数量不限。

```
┌─────────┐ ┌─────────┐ ┌─────────┐
│ ◉ 高三1班│ │ ◉ 高三2班│ │ ◉ 高三3班│   每张卡：
│ 笃学慎思 │ │ ……      │ │ ……      │   · 代表色描边 + 名次徽章
│ ▂▂▃▅ 612 │ │      598│ │      587│   · 形象 + 班名 + 口号
└─────────┘ └─────────┘ └─────────┘   · 总均分迷你条
```

- hover 卡片抬升 + 形象眨眼；点击弹出班级详情（含优势科目徽章）
- 详情页有「设为 PK 选手」按钮 → 带进擂台视图

### 4.2 榜单（排行榜）

纵向榜单 + 顶部前三领奖台，按所选指标排序（tabs 切换：总均分 / 上线率 / 进步 / 稳定性）。

- 榜单行：名次牌｜形象小图｜班名｜口号（小字）｜指标条｜数值｜较上次 ↑↓
- 前三名进领奖台（1 居中高台，2/3 分列），**颁奖动画见 §7**
- 与上次考试对比：名次升降箭头 + 换位动画

### 4.3 擂台（PK 对战）—— 动画主秀

```
        ┌─────── 高三(1)班 ──────┐   ┌─────── 高三(2)班 ──────┐
        │   ◉ （形象·胜利姿势）   │VS │   ◉ （形象）            │
        │   「笃学慎思，力争上游」 │   │   「……」               │
        ├────────────────────────┤   ├────────────────────────┤
        │ 语文 ██████████░░ 118  │   │ 语文 ████████░░░░ 112  │  ← 回合制逐科揭晓
        │ 数学 ███████░░░░ 105   │   │ 数学 █████████░░ 121   │
        │ ……                     │   │ ……                     │
        └────────────────────────┘   └────────────────────────┘
                        总分  612  VS  598   → 胜方彩带 + 数字滚动定格
```

- **开场**：VS 画面——两形象从左右弹入，口号以横幅/对话框弹出
- **回合制**：逐科揭晓比条，赢的一侧闪光，回合标签像格斗游戏 HUD
- **终局**：总分数字滚动定格，胜方彩带 + 胜利姿势，**负方给「潜力股」鼓励文案**（教育正向，不做嘲讽动画）
- 口径提示：只列两班共同科目，顶部一行小字注明比较口径

### 4.4 优劣势科目（并入擂台/详情页）

每科目一组**双向对比条**（左班向左生长、右班向右生长，谁长谁亮）：

- 差异最大的科目自动标注「优势科目」「待提升科目」
- **全员有高光**：每班都发一枚「最强科目」徽章，弱班也有亮点

## 5. 班级档案（设置页扩展）

设置页「班级」区块升级为档案编辑（每班一行卡片）：

- **班名**（沿用现有校验：非空、不重复）
- **口号** ≤16 字（阵列、榜单、擂台横幅展示）
- **代表色**：9 色复古色板选一（也支持自定义取色）
- **形象**：形象选择器（内置库 + 上传）
- **「一键生成 9 班模板」**：清一色默认班名/口号/配色/形象，生成后逐个改
- 增删逻辑沿用现有实现（删班确认、新建默认名），数量不限

## 6. 形象库（IP 系统）

**风格**：与「哈绩咪」统一——圆润、复古色调、描边风，一套看下来是一家人。

**来源两条路**：

1. **内置预设**（推荐混合方案）：
   - 哈绩咪 PNG 保持现状作为默认形象；
   - 其余 8~11 只用 **内嵌 SVG 印章风** 简笔形象（体积≈0、可随代表色换色、缩放不糊）；
   - 若想要全彩立绘，用 magpie-image（Flora）批量出 9 只统一风格透明底 PNG——代价是单文件会从 ~280KB 涨到 1MB+（每张 ~100KB 嵌入），或改为存 localStorage 不嵌 HTML。
2. **自定义上传**：压缩到 256px 后存 localStorage（控制在 ~30KB/张，9 班 ~300KB，5MB 上限安全）。

**1.1 进阶**：表情差分（常态 / 领先欢呼 / 落后打气 / 胜利），PK 动画时切换表情。

## 7. 动效设计（需求④）

**原则**：CSS keyframes + Web Animations API 为主，零依赖、单文件不破功；`prefers-reduced-motion` 时全部降级为淡入淡出。

| 场景 | 动效 | 技术 |
|---|---|---|
| 名次定格 | 数字滚轮（老虎机式）停在名次 | RAF 数字滚动 |
| 榜单入场 | 按名次从下往上依次浮现，前三弹跳 | CSS transition + 递增 delay |
| 领奖台 | 1/2/3 台座从下升起 + 彩带飘落 | keyframes + 随机彩纸粒子 |
| PK 对峙 | 两形象从左右滑入 + 轻微弹跳/摇晃 | keyframes |
| 口号横幅 | 开场弹入、结束弹出 | keyframes |
| 科目回合 | 比条从中线生长（力量条式），赢方闪光 | transform: scaleX + box-shadow |
| 总分揭晓 | 数字滚动 + 胜方彩带 | RAF + 粒子 |
| 名次变动（跨考试） | 两行交换位置 | FLIP + WAAPI |
| 微交互 | 卡片 hover 抬升、形象眨眼 | CSS |

性能注意：9 班同屏动画只用 `transform`/`opacity`，不触发重排。

## 8. 视觉

- **延续复古账页风**：米色纸底、衬线标题、细线边框、印章感——PK 页是「课堂擂台」，不是电竞馆。
- **9 色战队色板**（复古矿物色）：砖红 / 赭石 / 芥末黄 / 橄榄绿 / 墨绿 / 靛蓝 / 藏青 / 梅紫 / 炭棕。
- 竞技感来自 HUD 排布（VS、比分条、回合标签）与动效节奏，底色气质不变。
- 深浅色主题沿用现有双主题变量。

## 10. 风险与取舍

| 风险 | 对策 |
|---|---|
| localStorage 5MB 上限 | 上传图一律压缩 256px；内置形象用 SVG 不占存储 |
| 拼班 / 物理类 vs 历史类口径不齐 | 只比共同科目；口径提示沿用 V4 的严谨风格 |
| 全 PNG 嵌入导致单文件臃肿 | 混合方案：SVG 内置 + PNG 上传存 localStorage |
| 9 班动画卡顿 | 只动 transform/opacity；粒子数量设上限 |
| PK 伤士气 | 负方给「潜力股」鼓励；每班必有「最强科目」徽章 |
