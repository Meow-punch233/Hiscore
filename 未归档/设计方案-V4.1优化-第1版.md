# 成绩追踪系统 V4.1 设计 / 修改方案 · 第 1 版

> 基底：`Hiscore_v1.0.html`（品牌皮 + 班级 PK 线；原文件不动，另存产出）
> 产出：`Hiscore_v1.1.html`（用户指定：仅此一个文件、无后缀；V4.1 的改动全部并入这条线）
> 四项需求：① 学生成绩雷达图 ② 板块一键批量导出 PDF ③ 两种模板的区别（答疑） ④ 选科 bug 修复

**版本谱系备注**：目录里的 `Hiscore_preview.html`（= V4.0 + 哈绩咪品牌皮）和 `Hiscore_v1.0.html`（= 品牌皮 + 班级 PK）是并行分支。本方案的改动同套两个分支通用，最终按要求落在 `Hiscore_v1.1.html`。

## 一、需求①：学生成绩雷达图

**落点**：「学生追踪」页 —— KPI 区之后、分科卡片之前插入一张「学科能力雷达」卡；PDF 导出的"每人一页"里同样放一张。

**图的内容**
- 6 条轴：语文、数学、英语、首选科目、再选科目 1、再选科目 2 —— 按**该生的选科组合**动态生成（拼班学生用各自组合）。
- 数值：**得分率 %**（原始分 ÷ 满分；赋分科目按赋分 ÷ 100），各科才能横向比。
- 两个图层：
  - 本人：accent 色半透明多边形 + 顶点圆点；
  - 班级均分：虚线多边形（对照）。
  - 图例可点击叠加「年级均分」「上次考试」（默认关）。
- 网格环 20/40/60/80/100%，轴标签带数值（如 `数学 78%`），暗色模式自动适配。

**实现**：手绘 SVG，复用现有 `lineChartCard` 的主题变量 / 字体 / 配色风格（现有代码 2654 行附近已有手绘 SVG 折线图的先例），**不引第三方图表库**。新增 `radarChartCard(opts)` 函数；数据取 `computeAll()` 已有的各科分数与 `stats.subjAvg`（班级均分；年级均分加一个小统计函数）。

## 二、需求②：板块一键批量导出 PDF

**机制选型：浏览器打印式**（`window.print()` → 打印对话框里选「另存为 PDF」）。

理由：这个工具是单文件离线 HTML——打印式**零依赖、中文矢量清晰、A4 自动分页**；jsPDF 需要内嵌 5–10MB 中文字体，html2canvas 出图是糊的位图，都不适合。页面上会写明"在打印窗口选「另存为 PDF」"。

**入口两个**
1. 每个板块卡右上角「⬇ PDF」→ 只导出这个板块；
2. 「**一键批量导出 PDF**」按钮（放在"成绩录入"导出区 + 总览顶部）→ 打开导出面板。

**批量导出面板（勾选 + 范围筛选）**
| 板块 | 内容 | 范围选项 |
|---|---|---|
| 总览信息 | 最近一场 KPI、各班均分、上线率表 | 全部 / 某班 |
| 学生追踪信息 | **每人一页**：KPI + 雷达图 + 分科成绩表 + 偏科判定 + 简报文字 | 全部学生 / 某班 / 指定学生 |
| 偏科追踪信息 | 关注/预警名单汇总表：学生、班级、失衡科目（幅度）、判定档位、建议 | 全部 / 某班 |

**打印稿结构**：封面（班级、场次、生成日期）→ 各板块分节，每节 `page-break-after` 起新页，页眉带场次名。

**实现**：隐藏 `#print-root` 容器 + `@media print` 专用样式（只显示 print-root；`@page` A4 边距；`print-color-adjust: exact` 保留配色；SVG 图表矢量直出）。新增 `buildPrintDoc(sections)` 拼装函数。原有 CSV / JSON / 简报导出全部不动。

## 三、需求③：下载名单模板 vs 空白模板（答疑）

两个都是 CSV（Excel / WPS 打开），**列结构完全一样**：学号、姓名、班级、选科组合、年级排名 + 各科成绩列（按「设置」里的组合动态生成）+ 赋分列。

| | 空白模板 | 名单模板 |
|---|---|---|
| 内容 | **只有表头**，从零填 | 表头 + **全班名单预填**：学号 / 姓名 / 班级 / 选科组合 / 年级排名（上一场的参考值），**分数列留空** |
| 用途 | 新班级、第一次录入 | 保留学号 → 跨场追踪稳定、重名可区分，不用手抄名单 |
| 兜底 | — | 一场学生都没有时自动退化为空白模板并提示 |

**顺手改进**：这次要问就说明按钮不自明——两个按钮下加一行说明文字（"名单模板=带全班名单，学号姓名已填好，只补分数和年排；空白模板=只有表头"）。

## 四、需求④：选科 bug —— 实测结论与修复

### 实测发现（在浏览器里复现，V4.0 与 Hiscore_v1.0 代码同源，结论通用）

1. **换科死锁（确凿）**：「选科组合」表的再选两科勾选框，规则是"必须恰好 2 门，否则回滚"。已有组合是 2 门时——勾第 3 门被拦（3≠2）、取消 1 门也被拦（1≠2）。**结果：组合的科目一旦定下就永远改不了**（实测弹窗：「再选科目必须恰好 2 门（3+1+2 口径）。当前选了 3 / 1 门。」）。改班级选科的前提是组合本身得对，组合改不动 → 体感就是"新增 / 已有班级都无法修改选科"。
2. **"物化政"不识别（确凿）**：
   - 组合名输入框：输入"物化政"只改了名字，首选 / 再选科目**不会跟着变**（实测：名字变"物化政"，科目还是物化地的化+地）。名字与科目脱钩后，导入按名匹配还会配错组合；
   - 导入匹配 `matchComboByName`：只按"名字包含"匹配，不解析简称的科目构成。默认 5 组合（物化地/物化生/物生地/历政地/历政生）里没有"物化政" → 实测返回 null。
3. **班级勾选组合本身是好的**（实测勾选、保存、刷新都正常），但两个体验问题让"改选科"像改不了：
   - 每点一次勾选就 `render()` 且 `window.scrollTo(0)`，页面瞬间跳回顶部，行都找不到了；
   - 想要的组合（如物化政）不在勾选清单里，又不能快速新建 → "新增班级不可修改选科"。
4. 另注：如果你们遇到的是"改了班级组合但**已导入学生**的选科没变"——这是设计如此（学生组合以导入表为准，班级组合只用于推断）。修复项 G 可解决。

### 修复设计

| # | 改什么 | 怎么改 |
|---|---|---|
| A | 新增简码解析器 `parseComboText()` | 解析"物化政""物化地""历政地"等 3 字简码、"物理化学政治"全称、混写 → `{track1, track2}` |
| B | 组合名 ↔ 科目联动 | 名字输入框输入即解析（`oninput`，简码完整才触发、不影响打字），解析成功就自动设置首选/再选并**就地更新本行控件 + 立即落盘**（不整页重绘）；失焦再兜底校一次；一致时显示"✓ 名称与科目一致" |
| C | 导入匹配升级 | `matchComboByName` 先按名，再按**科目构成**匹配（解析简码 → 找科目相同的组合）。"物化政"从此能配上任何物理+化+政的组合 |
| D | 换科不再死锁 | 勾第 3 门时不再回滚，而是**自动替换**先选的那门（提示"已把生物换成政治"）；取消到 1 门允许暂态 + 行内提示"再选科目需恰好 2 门"，保存/离开时校验 |
| E | 班级行快捷选科输入 | 每个班级（含新增）加一个输入框（占位"选科，如 物化政"）：回车 → 解析 → 已有同科目组合就勾上，没有就**自动新建组合**并勾上；新增班级后光标自动落进这个框 |
| F | 修滚动跳动 | 设置页内部变更保存后保持滚动位置，只在切换 tab 时 `scrollTo(0)` |
| G | （可选）重推学生选科 | "按班级组合重推学生选科"按钮，用于导入表没带组合列、按班级推断的学生 |

## 五、改动清单（函数级）

**新增**
- `parseComboText()` — 简码/全称解析
- `radarChartCard()` — SVG 雷达图
- `buildPrintDoc(sections)` + `@media print` 样式块 + 导出面板视图
- 班级行"选科快捷输入"控件

**修改**
- `matchComboByName()` — 追加科目构成匹配
- 选科组合表再选勾选 handler — 替换式换科（去死锁）
- 组合名 `oninput` handler — 解析联动
- `renderSettings()` 班级行渲染 — 加快捷输入
- `render()` — 滚动行为
- `renderStudent()` — 插雷达图卡
- `renderEntry()` / `renderOverview()` — PDF 入口
- 模板按钮区 — 加说明文字

**不动**：赋分计算、排名口径、导入校验主流程、CSV / JSON 导出、AI 配置。
