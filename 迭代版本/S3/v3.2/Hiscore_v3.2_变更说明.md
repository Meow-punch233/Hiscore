# 哈绩咪 Hiscore v3.1 · 大学试验修正版

文件：`Hiscore_v3.1-university-fixed.html`  
基于审查过的大学预览版另存，不覆盖预览底稿或正式 v3.1。

## 这版做什么

优先把学分、绩点、加权平均做稳；同时保留并修好自定义满分/及格线/绩点区间，以及平时、期中、期末按比例合成。通过/不通过可以继续用，但不是主线。

定位仍是**按学期选课的个人成绩单**，不是全班各自选课。

## 修了什么

- **缺考 / 未修可以存住。** 总分制、分项课、通过制都会保存状态旗标，刷新后仍能区分：空白、未修、缺考、真实 0 分。缺考不补零；未修不算已修；缺考计入已修、不计入通过、不进平均。
- **大学导入模板。** 可按本学期或全部学期下载 CSV。先预览再确认写入。未知课程 ID 会留在预览里并报错，不会静默丢失；表中没有的已有成绩会保留；空白行不覆盖已有记录。
- **完整备份含大学数据。** Excel 精确备份与 JSON 备份都包含 `data.university`（课程、分项、权重、学期、规则快照、GPA 区间、成绩）。恢复确认框会写明大学数据也会被覆盖。旧格式 Excel 恢复会警告将清空大学数据。
- **去掉过时脚注**「大学……本版未开放」，改成与「大学 · 实验性」入口一致的说明。
- **切换课程时若有未保存修改，必须先确认**，取消则保留草稿，不再悄悄丢掉还清掉报错。
- **学分统计可看全部学期**（默认全部学期），也可再选单个学期。通过/不通过课不进数值平均。
- 绩点区间未配置或不完整时不显示 GPA；不硬编码全国标准。分项权重要求合计 100%，缺项为未完成，不为 0，不擅自配平。
- 修正大学样式误嵌在上一层 `<style>` 里的标签问题；补了导入区样式，并写明这是个人成绩单。

## 没改什么

初高中计算、赋分、G1/G2、原导入逻辑未作为功能改写。大学数据写在 `data.university`，不写入 `exams`。存储 key 仍是 `aki-grade-tracker-v31`。
