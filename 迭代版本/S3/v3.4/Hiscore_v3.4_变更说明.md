## 1. 设置页口径同步（P2-1）

- 偏科判定说明改为 v3.4 校准口径：科内 Z + 留一法 SEM（ρ=0.80，单侧 FWER≤5%），watch D≥1.60 且 t≥2.39、severe D≥2.10 且 t≥2.94。
- 旧 `selfGap` / `severeGap` 滑杆**移除**，替换为固定校准阈值说明块（不可调）；保留仍生效的名单佐证滑杆（vsAvgGap / rankTail / minRanked），文案改为「真实单科位次 N_k」口径。
- 同步更新：学生页判定副标题、家长版 PDF 口径行、总览/学生偏科标记（改显示 D 的 SD 值）、mismatch 注释。

## 2. 大学模块字母绩点（P2-3）

- 新增第三种计分方式 `letter`（与 score / passfail 并列），课程编辑器可选「字母→绩点口径」：HKBU 4.00 / EdUHK 4.33。
- 字母→绩点表：A+=4.33(EdUHK)/4.00(HKBU 封顶)、A=4.00、A-=3.67、B+=3.33、B=3.00、B-=2.67、C+=2.33、C=2.00、C-=1.67、D=1.00、F=0。**常见校历口径，界面明示以注册处公布为准**。
- GPA 直接取字母绩点（不经百分比分段）；字母中位百分比（A+ 97.5 … F 50）仅作显示与加权平均得分率的代理，脚注写明。
- 与既有口径合并：重修只取最高一次（学分计一次）、缺考计入已修且 GPA 按 0、未修不计、空白不算已修；百分比课仍走自定义区间（区间非法时百分比课不进 GPA，但字母课不受影响）。
- 录入 UI：字母下拉（含各字母绩点预览）+ 状态（缺考/未修）联动禁用 + 实时 GPA 预览；课程列表/明细行/统计卡显示字母与 GPA；CSV 导入模板与解析支持字母列（大小写归一、非法字母报错）。
- 统计卡改名「GPA（按课换算）」，注明字母课取字母表、百分比课按自定义区间、非官方认证。

## 3. 资产外置与体积（P2-2，本轮不托管）

- 14 处内嵌 Base64（14 个文件：2 png + 12 webp）外置为 `assets/img-01…14`；index.html 改相对引用；CSP img-src 增加 `'self'` 与 `file:` 以支持 file:// 双击离线。
- 外置版仅做**安全 CSS 瘦身**（去注释/空行/行首缩进，不动字符串与 JS）；内嵌单文件保持原样。
- 实测体积：index.html **1,006,496 B（0.96 MB）**；assets 合计 649,393 B（0.62 MB）；内嵌单文件 1,899,232 B（1.81 MB）；站点 zip 909,843 B。
- 达标情况：HKBU 单文件 ≤2MB、EdUHK ≤4MB 均满足且余量 ≥1MB。**自设 0.95MB 拉伸目标未达成（差约 10KB）**，原因是遗留 CSS/JS 体量；不再为凑数做有风险的 JS 压缩。
- 托管按用户决定本轮不做；站点包上传任意静态托管（GitHub Pages / Netlify）即可，目录结构已就绪。

## 4. 全英文案例演示页（P2-4）

- `Hiscore_v3.4_case_en.html`：复用 v3.4 同一计算核心与同种子合成数据（seed 20261029），同一暖纸像素视觉层；**界面全英文**，学生以匿名 ID 显示、班级译作 Class 3-n。
- 内容：双语演示横幅（EN）、Cohort KPI、校准关注列表（含 D/t 与口径说明）、学科雷达（得分率轴 + 班级/年级参考线）、同选科组合班级擂台（绝对得分率 + ★ + pp）、字母绩点面板（HKBU 3.08 / EdUHK 3.13 双口径对照表，含重修与缺考示例）、Methods/privacy/provenance 声明。
